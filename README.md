# Speedcubing

- [Cubing Badge Generator](https://github.com/ulcuber/cubing-badge-generator) to generate certificates/badges/diplomas for speedcubing events using python script to convert CSV participants list to images using `.scm` schemes for GNU Image Manipulator (aka Lisp GIPM script) to fullfill `.xcf` templates. Has dedicated funcubing format script. Uses cubingrf design for templates. Supposed to be used with `imagemagick` to glue all diplomas together in `.pdf` for printing
- [figtimer](https://github.com/ulcuber/figtimer) fork of TTY timer on figlet with more instructions, configurable delimeters, max times for marathons and copying results to clipboard (`xclip`). Shows best, worst, avg, mean calculated on demand
- [Image Creator](https://github.com/ulcuber/image-creator) refactoring of the old Canvas rendering used on [BSA](https://vk.ru/cubing_alg) (Base of Speedcubing Algoriths)
- [BSA API](https://github.com/ulcuber/bsa-api) Base of Speedcubing Algorithms API after refactoring from pure PHP. Archived due to different view on the project development with its original creator

Anyway <https://speedcubing.ru/tutorial/3x3x3/fridrich/f2l> has all the algs. Consider <https://cubingtime.com/> as timer and community or Open Source <https://www.cubedesk.io/> with trainer. So you have enough tools to keep your favourite algs to archive the BSA project
